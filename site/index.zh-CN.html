DEEPSEEK HARNESS · CADENCE VIRTUOSO

dsh-virtuoso-bridge

让智能体亲手操作 Virtuoso。

围绕上游 Virtuoso Bridge 的 DeepSeek Harness 插件：上游负责把智能体接入 Cadence Virtuoso CIW， 本插件负责一键部署 —— 隔离 venv、固定版本源码、CIW 守护进程 setup —— 并让它在多个会话之间长期存活：对话、fork 和子智能体共用同一套托管隧道与 守护进程，自动会话发现负责选中正确的实例或工作目录。

从安装开始 → 查看智能体工具

一键部署 多会话互通运行时 4 个工具 MIT 许可

插件负责什么

会话会结束，
bridge 不会。

运行时、隧道、守护进程和隔离 Python 环境都由插件的 Host 端管理。同一 profile 里的每个会话、 分叉和子智能体，用的都是同一个在线 bridge。

01

托管运行时

启动、停止、重启与测试连接。状态跨会话保留，并投影到右侧运行时面板。

02

完整 Python API

描述并调用任意公开的 virtuoso-bridge 目标 —— 原理图、版图、库、Maestro、弹窗、Spectre —— 中间没有插件包装层。

03

批处理脚本

在新的 venv 进程里运行 Python，可直接使用已连接客户端，支持 job、进度与取消。批处理出错不会破坏连接。

04

CIW 感知

调用期间 CIW 打印的警告与 *Error* 行会随结果一起返回，静默失败也有迹可循。

四个工具，一个 bridge

智能体需要的都有，
无需猜测。

工具注册在 Host 端，profile 内每个会话都能用。长任务变成 job；过大的答案写成文件， 智能体可以自己读或 grep。

RUNTIME

连接与观测

查状态、启动、停止、重启、ping、发现实例、部署守护进程、信任主机密钥、编辑连接。

virtuoso_bridge_runtime action=status
virtuoso_bridge_runtime action=start connection=lab
API

先描述，再调用

对已安装 bridge 的 describe 分三级：目标索引、单目标的方法列表、单方法的完整文档。然后直接调用。

virtuoso_bridge_api action=describe target=client.layout
virtuoso_bridge_api action=call target=client method=execute_skill
SCRIPT

批量执行 Python

内联代码或工作区文件，每次运行一个独立 job，带 connect()、emit()，结果持久保存。

client = connect()
result = {"windows": client.schematic.list_windows()}
SETUP

修复 venv

安装、更新、诊断、切换来源模式与清理缓存，安装日志保存在配置页。

virtuoso_bridge_setup action=status
virtuoso_bridge_setup action=diagnose

智能体工作循环

先读状态，
再动手。

插件刻意不做第二个 runner、job store、dialog manager 或调度器，只把 bridge 暴露出来，逻辑都在 bridge 里。

步骤 01

读取运行时

一次 status 调用即给出环境、隧道、守护进程、实例、已关联智能体与进行中的操作。

步骤 02

描述 API

以已安装的 bridge 为准；调用前先描述，不要猜签名。

步骤 03

批量处理工作

一个较大的脚本胜过许多次往返。用 path 指向可编辑、可重跑的文件。

步骤 04

读回 CIW

返回块带着共享 CIW 日志里的警告与错误 —— 先读它，别急着猜为什么没生效。

首次运行

安装 bundle。
创建 venv。
选定守护进程。

npm 包自带固定版本的 bridge 源码，安装既不需要 git 也不需要 submodule 检出。 本地只需先确认 Python 3.9+ 与 OpenSSH。

  1. 01通过插件管理器安装 bundle @nekomona/dsh-virtuoso-bridge。
  2. 02在左侧面板列表打开 dsh-virtuoso-bridge，点击 安装 创建隔离 venv。
  3. 03新增连接并启动，或在 CIW 空闲时先部署守护进程 setup。
  4. 04在 CIW 中运行打印出的 load("...") 行；健康轮询会把运行时转为 running。
完整安装步骤 →
Virtuoso CIWSKILL
load("/home/username/.virtuoso-bridge/daemon/virtuoso_setup.il")
智能体工具调用DSH
virtuoso_bridge_runtime({ action: "status" })
virtuoso_bridge_api({
  action: "call", target: "client", method: "execute_skill",
  args: ["1+1"], description: "Check the daemon answers"
})
